FLAGSHIP PROJECT

PROJECT 01

HetuSafe

HetuSafe (formerly Project SAVE) is a live, community-powered civic hazard-reporting platform built and operated end-to-end, from product design and backend services to cloud deployment. It combines camera-first reporting, real-time geospatial updates, community verification, trust/reputation scoring and location-aware notifications. Public beta completed with 50 real testers, backed by 81 automated tests, protected CI/CD and production monitoring. Kubernetes orchestration is currently being implemented for future scale.

React + Vite Node.js + Express PostgreSQL Redis MapLibre GL JS Docker AWS GitHub Actions Jest + Supertest Kubernetes (In Progress)
